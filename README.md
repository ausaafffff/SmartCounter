# SmartCounter

A simple counter application built with **MIT App Inventor**.

## Overview

SmartCounter is distributed as an MIT App Inventor project archive (`SmartCounter.aia`). The project contains the app's screen components and block-based logic and can be opened directly in MIT App Inventor.

## Features

- Increment and decrement counters
- Reset the counter
- Simple mobile-friendly interface

## Getting Started

### Prerequisites

- A [MIT App Inventor](https://appinventor.mit.edu/) account
- A web browser
- An Android device or emulator for testing (optional)

### Import the Project

1. Download `SmartCounter.aia` from this repository.
2. Open [MIT App Inventor](https://appinventor.mit.edu/).
3. Select **Projects > Import project (.aia) from my computer**.
4. Choose `SmartCounter.aia`.
5. Open the imported **SmartCounter** project.

### Run the App

1. Connect an Android device or start an emulator.
2. In MIT App Inventor, click **Connect** and select **AI Companion** or your emulator.
3. Build and install the app using **Build** in the MIT App Inventor menu.

- `Screen1.scm` — screen component and layout definitions
